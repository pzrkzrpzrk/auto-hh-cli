# Тикеты по ревью auto-hh-cli

Источник — [`REVIEW.md`](../../REVIEW.md) (полный отчёт KISS/DRY). Каждый тикет ≈ один коммит.
Приоритеты унаследованы из TL;DR отчёта: **P0** — корректность/производительность, **P1** — крупные дубли,
**P2** — удаляется/сокращается без изменения поведения, **P3** — шум. Если тикет собирает несколько пунктов,
указан максимальный приоритет из входящих.

> (легаси-обёртка `src/apply-playwright.ts`, `@types/node` в `dependencies`, устаревшие `@types/node-cron`,

> состояние кода **до** соответствующих правок.

> шаги, активное резюме в `ctx`, ошибка подменю, Ctrl+C).

## Общие условия приёмки (для любого тикета)

- `npx tsc --noEmit` → **exit 0** (в проекте нет автотестов, это единственная автоматическая проверка).
- Поведение меню, имена env-переменных, схемы Mongo-коллекций и формат `.md`-дайджеста **не меняются**.
- Каждый тикет — отдельный коммит с сообщением `refactor(<scope>): <что>` либо `fix(...)` / `chore(...)`.

## Что нельзя проверить в этом окружении

Полный прогон требует MongoDB, Playwright-профиля с живой сессией hh.ru и ключа ИИ. Доступны безопасные
ручные проверки: вывод `config`, `digest show` (чтение Mongo), ветка ошибки `cover` без ключа, отмена промптов (Ctrl+C).
